# SkillKita

Web-based training and course management system for **TRSC** (quotations, courses, documents, messaging, and AI assistance).

**Full setup manual and project overview:** see [`skillkita-web/README.md`](skillkita-web/README.md)

```bash
cd skillkita-web
npm install
cp .env.example .env   # then fill in Supabase / Gemini keys
npm run dev
```
